# External Profile Review — Evidence Notes

## Facebook

Publicly visible as a Coreweaver Labs city-infrastructure page with zero followers. Its stated purpose concerns smarter cities and urban environments, which does not match the current website's GEO / AI representation positioning. The profile also exposes several legacy or inconsistent social and product links.

## X

The `@coreweaverlabs` profile uses positioning that closely matches the current site: AI and search signals, evidence, influence, gaps, and discoverability. It is new (joined June 2026), has two visible posts and zero followers, so it is credible as an official handle but not yet strong social proof.

## LinkedIn

The public company page has recent activity and links to `coreweaverlabs.com`, but its visible company description is still about city infrastructure, autonomous resource management, and an internal conflict between its current agentic-AI post theme and legacy company profile. It should be updated before it is used as a prominent trust signal.

## Substack

The public landing page identifies the publication as `COREWEAVER` and says it launched about a year ago. Substack’s page was gated behind a CAPTCHA, so the public archive and recency could not be fully assessed in this session. Its page title is potentially a strong fit for an Insights strategy, conditional on editorial quality and a consistent current publication cadence.

## GitHub

The `Coreweaver-Labs-Inc` organization has one public HTML repository, two stars, no public members, and visible activity last updated in June 2026. It can support a transparent builder ethos, but it is not yet substantial enough to be presented as proof of a mature open-source program.

## Recommendation

Use LinkedIn and Substack as the two intended credibility channels after their profile copy and editorial activity are aligned to the current GEO / AI-representation proposition. Add X in a compact social row rather than as a major trust marker while the audience is still forming. Do not feature Facebook in the current site footer or structured social links until the legacy urban-infrastructure language and unrelated links are corrected. Keep GitHub as an optional "technical work" link in the footer or a dedicated proof/engineering page, not in the primary brand navigation.
