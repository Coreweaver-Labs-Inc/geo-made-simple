# Coreweaver Labs Visual System — Image-by-Image Direction

## Purpose

This visual system replaces decorative abstraction with **emotionally purposeful infrastructure imagery**. Each asset must move a mid-market B2B buyer through a sequence: confront the cost of an unclear market identity, feel safe in a disciplined method, understand the next step, and want the calmer, more coherent future the work makes possible.

The images must never imply rankings, client results, revenue, review volume, security guarantees, or an AI capability the company cannot substantiate. They are visual metaphors for clarity, governance, and decision readiness—not evidence of outcomes.

## Shared Art Direction

| Design element | Direction |
|---|---|
| Visual territory | Editorial architectural still life, precision instruments, engineered materials, measured light, and quiet signal infrastructure |
| Emotional register | Controlled tension resolving into order; never cold, panic-driven, generic, or triumphalist |
| Palette | Warm mineral paper, deep graphite, smoked black, oxidized brass, and restrained signal teal |
| Light | A single directional beam, soft ambient shadow, and subtle teal reflected light; no neon glow or “AI brain” effects |
| Composition | Asymmetrical but balanced, with deliberate negative space for adjacent web copy; text-free imagery only |
| Materials | Paper, aluminum, graphite, fine mesh, glass, brass, measurement marks, optical fibers, and engineered folds |
| Explicit exclusions | Humanoid robots, brain imagery, corporate handshakes, dashboards, people in meetings, stock-office scenes, blockchain motifs, floating code, and fabricated awards/results |
| Accessibility and SEO | Every image receives an informative alt text, an asset title, a contextual caption where appropriate, and an Open Graph alternative text. Decorative details are not described unless they carry meaning. |

## Sequence Logic

The visitor first meets **productive tension** in the hero, then moves into the **safety of an inspectable method**, the **clarity of connected tools**, and finally the **desire for a visible next step**. The mark remains stable across that progression so the visual change never feels like a change in identity.

## Production Acceptance Rules

1. Produce each environmental asset individually at high-resolution landscape dimensions, without text embedded in the image.
2. Use the metadata in this document exactly unless a generated composition materially changes what the image depicts.
3. Keep image descriptions descriptive rather than promotional; do not add unsupported claims to alt text, captions, filenames, JSON-LD, or social metadata.
4. Use the existing approved organization mark until a dedicated identity-review brief authorizes a change.
5. Validate each replacement at desktop and mobile crops before publishing.
